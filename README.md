## 🚀 Featured Projects

- **[SmartLane AI (Paranox 2.0 National Hackathon — 2nd Runner-Up)]**  
  Real-time computer vision system built with **YOLOv8** and **TensorFlow**, achieving **99.2% accuracy** in emergency vehicle detection to dynamically optimize 4-way intersection signals.
- **[Generative AI Resume Summarizer]**  
  Abstractive summarization pipeline powered by fine-tuned **T5 Transformers, GANs, and TextRank** to automate candidate screening and highlight core skills. Published in **Springer**.
- **[SimpleBit Crypto Platform](https://simple-bit.com/)**  
  High-frequency cryptocurrency tracking and management platform architected on the **MERN stack** with real-time RESTful APIs.
- **[NIELIT Secure Question Paper Platform](https://nielit.ac.in/)**  
  A **leak-proof, encrypted question paper generation system** using **SHA-256 hashing in SQL Server**, ensuring zero plaintext exposure to DBAs, paired with automated SSRS PDF generation.
- **[The Hidout Booking Engine]**  
  Engineered and optimized core backend availability, reservation flows, and admin notification systems for a property management platform.
- **[E-Commerce NLP Analyzer]**  
  Sentiment analysis pipeline using **NLTK, Scikit-Learn, and Pandas** to evaluate consumer reviews and improve online product ranking metrics.
- **[Aksumbase Platform](https://aksumbase.com/)** & **[DriveAI Navigation]**  
  Scalable full-stack backend architecture and AI-guided automotive UX workflows.
